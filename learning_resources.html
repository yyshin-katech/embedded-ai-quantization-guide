가이드의 참고문헌은 단계별로 흩어져 있고 대부분 배포 툴 문서다. "기초부터"에 맞게 난이도 순으로 재배열하고, 가이드에 없던 입문 자료를 보탰다.

단계무엇을 얻나자료 수예상 시간이 가이드의 대응 단계
Lv.0 감 잡기scale·zero-point·per-channel·outlier가 무슨 뜻인지5곳1~2h1단계 §2 읽기 전
Lv.1 공식 문서각 프레임워크가 실제로 제공하는 API와 PTQ 3종의 차이7곳3~4h0.5단계 Lv.2 / 1단계 §4
Lv.2 소스 코드문서가 거짓말하는 지점 — 실습에서 실제로 배신당한 항목만6곳2~3h1단계 실습 중 필수
Lv.3 하드웨어 제약"INT8인데 왜 안 빨라지나"의 답 — 백엔드별 지원 op·대칭성8곳4~6h3·4단계
Lv.4 도구직접 구현하지 말고 쓸 것6곳실습 중 참조2~5단계
Lv.5 한 학기체계적 심화2곳12주+가이드 완주 후
핵심Lv.2를 건너뛰지 마라. 1단계 실습에서 실제로 문서가 틀렸던 항목만 모은 층이다 — ORT의 Entropy가 기본값에서 MinMax와 바이트 단위로 동일한 모델을 뱉는다는 사실은 공식 문서 어디에도 없고 calibrate.py를 읽어야 나온다.
표기 규약각 링크에 출처 배지를 달았다. 가이드 23곳 = 가이드 참고문헌에 실제로 있는 링크 · URL 교체 2곳 = 가이드 링크가 죽어서 살아 있는 주소로 바꾼 것 · 보탠 자료 8곳 = 가이드엔 없지만 기초 학습에 필요해 내가 추가 · 링크 유실 1곳 = 대체 불가. HTTP 코드는 2026-08-06에 curl로 실측한 값이다(206 = Range 요청 정상 응답).
