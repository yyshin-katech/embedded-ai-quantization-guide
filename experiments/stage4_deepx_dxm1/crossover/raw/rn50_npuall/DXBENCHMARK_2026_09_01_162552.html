Metrics Glossary

FPS (Frames Per Second)

The number of frames the model processes per second. Higher values indicate better throughput performance.

NPU Inference Time

The time taken for the NPU Core to complete an inference operation. Lower values indicate faster processing on the NPU hardware.

E2E Latency (End-to-End Latency)

The total time for a single inference, including NPU task (data transfer + inference) and CPU task processing. Lower values indicate better end-to-end performance.

P50 / P99 (Percentiles)

P50 is the median value (50th percentile), representing typical performance. P99 is the 99th percentile, representing worst-case performance excluding outliers.

CV (Coefficient of Variation)

The ratio of the standard deviation to the mean (CV = σ / μ). A lower CV indicates more stable and consistent performance. Values below 0.1 generally suggest low jitter.
