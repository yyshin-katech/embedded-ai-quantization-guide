2단계 DETR INT8 양자화 — 실측 검증 보고서

facebook/detr-resnet-50(CNN backbone + Transformer head)을 실제로 ONNX export → 실패 채집 → 우회 → INT8 PTQ → COCO val2017 전량 5,000장 mAP까지 완주했다. 초안(04_transformer_quantization.md)의 경험적 단정 세 가지가 실측과 어긋났다: ① export 첫 블로커는 grid_sampler가 아니라 SDPA, ② "특정 op만 FP로 빼면 회복"은 +0.36 mAP로 사실상 실패, ③ 손상의 범인은 attention이 아니라 망 전체에 분산. 모든 명령·터미널 출력·mAP를 기록하고 초안을 실측으로 정정했다.

① export 첫 블로커초안 통념 "grid_sampler" → 실측 SDPA(opset14+). DETR엔 grid_sample이 아예 없다(Grid op = 0). (3절)

§6 — mixed 회복 실패 & 범인 절제

"가장 어려운 op(activation×activation matmul)만 FP로 빼면 회복"이라는 초안 가설을 직접 시험하고, 실패하자 범인 위치를 절제로 분리했다.

반증 op-선택 mixed로는 회복 안 됨

attention score matmul 36개(/model/*/self_attn/MatMul(_1), /model/*/encoder_attn/MatMul(_1))를 FP로 남겨도 mAP 0.2402 → 0.2438. 폭락 −0.1805의 2%도 못 되찾는다.

반증 "attention이 범인"

절제: transformer만 INT8 = 0.2391(거의 full 폭락), backbone만 INT8 = 0.2653. 두 절반이 각자 폭락 대부분을 만든다 — 손상은 특정 서브그래프가 아니라 망 전체에 분산(sub-additive, 두 절반의 손실 합 > 전체 손실).

핵심 해석 폭락의 지배 요인은 per-tensor activation 양자화 자체다. 소수의 "문제 op"를 골라 FP로 빼는 op granularity 전략은 DETR에서 무력하다. 진짜 레버는 activation 양자화의 입도를 바꾸는 것 — SmoothQuant(§2.2, outlier를 weight로 migrate)나 per-token/group activation 양자화(stock ORT QDQ엔 없음).

§7 — Percentile 캘리브 3중 실패

"outlier를 clip하면 per-tensor scale이 본체를 되찾는다"(§2.1.1)를 Percentile 캘리브(99.99/99.9)로 시험. stock ORT HistogramCollector는 DETR에서 세 방식으로 죽었다.

① 동적 shape이미지마다 activation shape가 달라 HistogramCollector가 stack 실패 → ValueError: ... inhomogeneous shape
② 고정 shape → OOM1066×800 고정(do_resize=False)으로 ①을 우회하면 이미지당 ~3.6GB → N=8에서 SIGKILL(peak 30.9GB/31GB, exit 137)
③ N=4 → infpeak 19GB로 들어가지만 numpy.histogram이 attention mask fill에서 inf를 만남 → ValueError: autodetected range of [inf, inf] is not finite
결론 stock ORT의 Percentile/Entropy 캘리브는 동적·고해상 detection 그래프에서 사실상 못 돈다. 스칼라 min/max인 MinMax만 생존 → 본 보고서의 모든 mAP는 MinMax 기준. 회복은 캘리브 방법 교체가 아니라 SmoothQuant/per-token으로 가야 한다는 6절 결론과 일치.
